# IT Support & Cybersecurity Project Portfolio

A static portfolio website presenting an IT support troubleshooting case study. The project demonstrates a structured approach to diagnosing a no-internet incident across Windows and Linux environments, from IP configuration checks through DNS validation and final recovery testing.

## Overview

This portfolio focuses on a realistic support scenario:

- Reported issue: no internet access through Wi-Fi or Ethernet
- Symptoms: limited connectivity, failed external pings, and failed domain lookup
- Root cause: invalid DHCP assignment causing loss of internet access
- Outcome: restored valid addressing, DNS resolution, and internet connectivity

## Features

- Responsive single-page portfolio layout
- Troubleshooting methodology section
- Windows and Linux command coverage
- Network architecture diagram
- Evidence gallery with command-output screenshots
- Before-and-after validation table
- Key learnings from the troubleshooting process

Then open:

